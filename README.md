# Python Sports Betting Arbitrage Project

Python project analysing sports betting arbitrage opportunities across 3,000+ professional men’s tennis matches.

## Overview

In this project, I investigate arbitrage opportunities in tennis betting markets using historical closing odds. The analysis examines how arbitrage opportunities vary across tournament level, surface, and round, and includes a backtest of an arbitrage betting strategy.

## Key Findings

- Analysed 3,000+ tennis matches across ATP Challenger and ITF men’s professional tennis tournaments.
- Compared arbitrage opportunities across five tournament levels.
- Investigated how surface and tournament round affect arbitrage opportunities.
- Found that grass-court matches had the highest average arbitrage return per match across the surfaces analysed.
- Backtested an arbitrage betting strategy using historical odds.

## Data

I manually collected historical tennis betting odds for this analysis. I have not included the underlying dataset in this repository due to restrictions on publicly redistributing the source data.
